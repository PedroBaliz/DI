Desenvolvimento de Interfaces

Repositório dedicado ao desenvolvimento e estudo de interfaces web, reunindo implementações práticas com HTML e CSS e fundamentos de usabilidade, acessibilidade e experiência do usuário.

Os projetos buscam ir além da construção visual da interface, considerando a forma como o usuário compreende, navega e interage com aplicações web.

Principais áreas

- HTML e CSS — estruturação, estilização e organização de interfaces
- Design Responsivo — adaptação para diferentes dispositivos e tamanhos de tela
- Acessibilidade Web — aplicação de boas práticas e diretrizes WCAG
- Usabilidade — análise e melhoria da interação com base em heurísticas
- IHC e UI/UX — desenvolvimento orientado à experiência do usuário
- Design Thinking — abordagem centrada no usuário para definição e solução de problemas

Foco do repositório

Aplicar conceitos de desenvolvimento front-end na construção de interfaces que sejam:

- Funcionais
- Responsivas
- Acessíveis
- Intuitivas
- Semanticamente estruturadas
- Centradas no usuário

Tecnologias e conhecimentos

HTML | CSS | Responsive Design | Accessibility | WCAG | UI/UX | IHC | Usability | Design Thinking

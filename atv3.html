Interação Humano-Computador (IHC)

O que é IHC?

A Interação Humano-Computador (IHC) é uma área que estuda a interação entre pessoas e sistemas computacionais.

Seu objetivo é tornar os sistemas mais fáceis, eficientes, acessíveis e agradáveis de utilizar.

Importância da IHC

  • Melhora a experiência do usuário;
  • Facilita a utilização dos sistemas;
  • Reduz erros durante a interação;
  • Aumenta a acessibilidade;
  • Melhora a eficiência das tarefas.

Design Thinking

O que é Design Thinking?

Design Thinking é uma abordagem utilizada para solucionar problemas de forma criativa e centrada nas necessidades das pessoas.

Principais etapas

  • Empatia: entender o usuário;
  • Definição: identificar o problema;
  • Ideação: criar possíveis soluções;
  • Prototipação: desenvolver modelos;
  • Teste: avaliar as soluções.

10 Heurísticas de Nielsen

O que são?

As heurísticas de Nielsen são princípios utilizados para avaliar a usabilidade de interfaces digitais.

As 10 heurísticas

  1. Visibilidade do status do sistema;
  2. Correspondência entre sistema e mundo real;
  3. Controle e liberdade para o usuário;
  4. Consistência e padrões;
  5. Prevenção de erros;
  6. Reconhecimento em vez de memorização;
  7. Flexibilidade e eficiência de uso;
  8. Design estético e minimalista;
  9. Auxiliar usuários a reconhecer e corrigir erros;
  10. Ajuda e documentação.

WCAG & Cores

O que é WCAG?

WCAG significa Web Content Accessibility Guidelines. São diretrizes desenvolvidas para tornar conteúdos da web mais acessíveis para todas as pessoas.

Princípios da acessibilidade

Perceptível

As informações devem poder ser percebidas pelos usuários.

Operável

A interface deve permitir que o usuário consiga interagir com seus elementos.

Compreensível

As informações e a interface devem ser fáceis de entender.

Robusto

O conteúdo deve funcionar corretamente em diferentes tecnologias.

Importância das cores

As cores devem possuir contraste adequado para facilitar a leitura e garantir acessibilidade.

É importante não utilizar somente a cor para transmitir uma informação.

UX/UI em Desenvolvimento

UX - User Experience

UX está relacionada à experiência que uma pessoa possui ao utilizar um produto, sistema ou serviço.

O objetivo é criar experiências úteis, eficientes e agradáveis.

UI - User Interface

UI está relacionada à interface visual de um sistema, incluindo cores, tipografia, botões, menus e outros elementos gráficos.

UX + UI

UX e UI trabalham juntas para criar interfaces funcionais, bonitas e fáceis de utilizar.
